# Changelog

- Added a new style guide page that pulls in the live stylesheets and documents every color, spacing value, corner rounding, shadow, button, tag, form, and text style used across the app.
- Introduced a consistent set of design tokens for spacing, corner rounding, font sizes, shadows, and animation timing.
- Reduced the number of gray tones, font sizes, and heading levels in use.
- Fixed several cases where identical elements rendered inconsistently depending on where they appeared.
- Unified several near-duplicate components (tag chips, pills, text inputs, popovers) into shared styles.
- Removed unused code and a few small bugs.
- Organized the stylesheets into clearly labeled sections for easier navigation.
