Typography

One family app-wide (Roboto 400/500/600/700). Typography is a set of complete text styles — each locks size, weight, case, letter-spacing and line-height. The only per-instance change allowed is colour / grey tone; interaction states (:hover / .selected) may change weight. Each row's name is rendered in its own style, so it doubles as the live specimen (from design-system.css).

Tracking: 0.03em (text) · 0.05em (CAPS label) · 0 (body). Leading: 1.2 (text & label) · 1.3 (body-sm) · 1.5 (body). Size primitives --font-10 … --font-36. Glyph buttons (+/-, edit, ···) are SVG icons, not type.

Shadows & Glass

The app's signature surface treatment is "frosted glass" — a shared translucent background + blur + hairline border, applied via .frosted-glass / .glass-surface (now merged into one rule under the hood; both class names still work). A --shadow-sm/md/lg/xl elevation scale has also been added to design-system.css for the bespoke shadows below — not yet applied to existing components, so their current hand-picked values are shown as-is.
