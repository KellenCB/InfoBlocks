Typography

One family app-wide (Roboto 400/500/600/700). Typography is a set of complete text styles — each locks size, weight, case, letter-spacing and line-height. The only per-instance change allowed is colour / grey tone; interaction states (:hover / .selected) may change weight. Each style is a utility class (.text-*) applied directly in markup; every specimen below is rendered with that class, so it's a live sample (from design-system.css).

Tracking: 0.03em (text) · 0.05em (CAPS label) · 0 (body). Leading: 1.2 (text & label) · 1.3 (body-sm) · 1.5 (body). Size primitives --font-10 … --font-36. Glyph buttons (+/-, edit, ···) are SVG icons, not type. Alignment modifiers: .text-left / .text-center / .text-right.

Glass

The app's signature surface treatment is "frosted glass" — a shared translucent background + blur + hairline border + the --glass-shadow elevation, applied via .frosted-glass / .glass-surface (one rule under the hood; both class names work). This is the default elevated surface: new panels, popovers, and dialogs should use glass rather than inventing a new shadow. Component-specific shadows do exist (coin bevels, toggle glows, board-card states) but they're owned by those components and shouldn't be reused elsewhere.

Motion

Durations are now tokens in design-system.css (--transition-xfast … --transition-slower), used 250+ times across the CSS. Panel/layout transforms also share one easing curve, --easing-signature (cubic-bezier(0.4, 0, 0.2, 1)). New transitions should reference a token, not a literal s value.

TokenValueTypical role
--transition-xfast0.1sInstant taps / tiny state flips
--transition-micro0.12sMicro hover feedback
--transition-fast0.15sHover colour/background — most common
--transition-medium0.2sHover / opacity transitions
--transition-dim0.25sDimming / de-emphasis fades
--transition-slow0.3sPanel slide, tag select, filter open
--transition-overlay0.4sOverlay fade-in
--transition-slower0.5sHP bar / progress fills
