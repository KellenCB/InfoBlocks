Typography

Single font family app-wide: Roboto, now loaded at weights 400/500/600/700 — every bolder weight below renders as true Roboto bold rather than a browser-synthesized fake.

Every distinct text style actually in use, grouped by size and weight (largest/boldest first) rather than by app area — so styles that look alike sit next to each other no matter where they're used. Every sample below is the real class/tag from the app — nothing here is a mockup. Default letter-spacing app-wide is 0.03em (a universal rule); a row's letter-spacing is only called out in its caption when it overrides that default.

Shadows & Glass

The app's signature surface treatment is "frosted glass" — a shared translucent background + blur + hairline border, applied via .frosted-glass / .glass-surface (now merged into one rule under the hood; both class names still work). A --shadow-sm/md/lg/xl elevation scale has also been added to Colourpalette.css for the bespoke shadows below — not yet applied to existing components, so their current hand-picked values are shown as-is.
